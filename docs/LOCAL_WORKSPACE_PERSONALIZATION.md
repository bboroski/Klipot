# Local workspace personalization

The Klipot project catalogue supports session favourites and an optional **Remember favourites on this device** setting.

- Favourites are available in memory for the current page session by default.
- Browser storage is not read until the user explicitly enables remembering.
- Opting out clears the in-memory favourites and removes the Klipot preference key from local storage.
- The preference stores only repository IDs; it does not store search history, identifiers, device information or browsing events.
- No analytics endpoint, cookie, account profile or background tracking is used.
- Users can filter the catalogue to favourites and clear them at any time.

This is a local navigation convenience, not a recommendation engine or remote personalization service.
