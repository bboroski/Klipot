# Klipot
**Ecosystem Integration & Control Plane**

[Українська](README.md) · [English](README.en.md) · [Русский](README.ru.md)

A static HTML/JavaScript portal for an engineering ecosystem: repositories, contracts, links and integration boundaries.

## Features
- Repository catalog with search and filters.
- Machine-readable registry and versioned integration protocol.
- Browser labs for local allocation, lifecycle and capability-gate demonstrations.
- CI checks for metadata, schemas, contracts and JavaScript.

## Run and test
```bash
python -m http.server 8080
# open http://localhost:8080
python one.py check
```

## Scope
Browser labs use local models and synthetic data. They do not run native C, read hardware telemetry or control devices. The portal does not merge independent runtimes.
