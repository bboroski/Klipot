# Klipot — Mesh Constellation UI

An abstract ecosystem map for the Klipot integration control plane.

## Design interpretation

The source sketch becomes a constellation rather than a conventional card directory: a narrow status strip, a large spatial field, independent repository nodes, explicit connector paths, a contextual inspector and a persistent bottom navigation rail.

The Klipot identity retains a restrained graphite, mineral and brass/yellow palette. Other repository interfaces keep their own product-specific colour systems.

## Preview

Open `index.html` in a modern browser.

## Interactions

- Select any of the eight companion repositories to inspect its responsibility and integration boundary.
- Search names and responsibilities.
- Filter nodes by language, system or operations domain.
- Open the source repository or inspect a contract note.
- Use the bottom navigation to access the constellation, contract guidance, browser-lab pointer and catalog view.

## Boundaries

Connection lines are conceptual relationships, not process calls or proof of runtime dependencies. The actual integration protocol and browser labs remain documented in the main Klipot portal.
